# Clustering stability

## Workflow

Post-QC counts → resolution scan → 30-round Pilot → manually narrowed candidates → independent 100-round Formal → resolution selection → Seurat objects for metacell analysis.

Configurations are provided for Adig, Ahya, Amur, Fusp, Gfas, Hcoe, Pdam, Plut, Xesp and Pcru. They already contain the adopted Pilot/Formal candidates. Spis reuses its reference object. Pilot and Formal are separate runs; all clusters in the selected partition are retained.

## Required files

- Post-QC Seurat RDS objects: set `input.seurat_rds` in each `<species>/config/config.yaml`.
- Supplied configurations and `<species>/input/<species>_metadata.tsv`, with cell IDs matching the RDS.
- R with Seurat/SeuratObject, Matrix, Rcpp/RcppAnnoy, yaml, ggplot2, data.table, mclust, aricode and clustree.

Large RDS objects and generated results are not bundled. Run all commands from **this module directory** and keep the generated run folders intact. Object rebuilding requires **R 4.3.3** and Seurat/SeuratObject/Matrix versions matching the recorded run.

## Running the scripts

**1. Scan, Pilot and Formal.** Set the input paths, then run for each of the ten species. Adig example; replace the configuration path for other species, including `Pcru/config/config.yaml`:

```bash
Rscript --vanilla workflow/run_cluster_stability.R Adig/config/config.yaml --stage=scan
Rscript --vanilla workflow/run_cluster_stability.R Adig/config/config.yaml --stage=pilot --marker-mode=none --pair-consensus=false --sensitivity=false
Rscript --vanilla workflow/run_cluster_stability.R Adig/config/config.yaml --stage=formal --marker-mode=none --pair-consensus=false --sensitivity=false
```

**2. Select resolutions.** Run after all ten species have scan/Formal results. Keep exactly one Formal run per species under `<species>/runs/`:

```bash
Rscript --vanilla resolution_selection/scripts/02_evaluate_all_species.R "$PWD" "$PWD/resolution_selection"
```

**3. Rebuild selected objects.** Use the full parameter table generated by step 2, together with its recorded input RDS files, frozen configurations and reference partitions. These files must remain accessible with matching checksums:

```bash
Rscript --vanilla resolution_selection/scripts/04_rebuild_selected_objects_260816.R \
  "$PWD/resolution_selection/03_cross_species_summary/tables/all_species_selected_resolution_and_reclustering_parameters.csv" \
  "$PWD/selected_objects" \
  "$PWD/workflow"
```

The compact `reference_results/selected_resolutions.csv` is for reference and cannot replace this generated table. If the adopted rebuilt objects are already available, proceed to [metacell construction](../metacell/README.md).

**Optional Pilot summaries and figures.** After scan/Pilot, use the current outputs and matching YAML settings. For the nine species excluding Pcru, run 07 successfully before 08:

```bash
mkdir -p summary manifests docs
Rscript --vanilla workflow/scripts/07_summarize_260810_structural_pilot.R "$PWD"
Rscript --vanilla workflow/scripts/08_plot_260810_unstable_cluster_distributions.R "$PWD"
```

Pcru is summarized separately:

```bash
mkdir -p summary Pcru/docs
Rscript --vanilla workflow/scripts/10_summarize_260811_Pcru_pilot.R "$PWD"
```

These summaries use the configured Pilot candidates/iterations; no historical batch tables are needed. They support candidate inspection before Formal selection.

Other retained entries are optional:

| Scripts | Use |
|---|---|
| `resolution_selection/scripts/03*`, `05*` | Validate selection outputs after step 2 and rebuilt objects after step 3, respectively |
| `workflow/scripts/11*` → `12*`; `13*` → `14*` | Alternative Formal batches after scan; create `summary/` and `manifests/` first. 11 checks all ten species; 12 runs nine excluding Ahya; 14 runs Ahya and Amur. These overlap in Amur and replace the corresponding per-species commands |
| `workflow/scripts/03*` → `04*` | General stability summary followed by targeted/posthoc analysis; separate from the adopted selection above. The driver's `all` option ends at Pilot summary |

## Final output

- `<species>/runs/<run_id>/`: scan and Pilot/Formal results.
- `resolution_selection/`: rankings, selected partitions and the full rebuilding parameter table.
- `selected_objects/<species>_selected_r<resolution>_reclustered.rds`: objects for metacell analysis.
- `summary/`: optional Pilot evidence; figures are in `structural_pilot_unstable_distributions/figures/`.
