# TF-associated OG expression and conservation

## Workflow

This module compares TF-associated orthogroup (OG) expression across corresponding cell types to identify shared transcriptional signatures. OG_SUM statistics → TF80 selection → species-level conservation → member contributions and expression heatmaps.

TF80 requires at least 80% TF-labelled members per OG; expression uses all OG members. Neuronal, immune and germline subtypes are combined only for species votes. Gland subtypes remain separate. Both calicoblast and epidermis comparisons include 11 species; `epidermis_like_1/2` are excluded as targets. Group membership, thresholds and display settings are in `config/`.

## Required files

Use Python and R with Seurat/SeuratObject, Matrix, data.table, jsonlite, digest, ComplexHeatmap and circlize. `Rscript` and Ghostscript (`gs`, used by the PDF check) must be available.

| Input | Location or preparation |
|---|---|
| OG_SUM objects | Eleven adopted objects are included at `../og_sum_conservation/intermediate/02_og_sum_objects/<species>.OG_SUM.seurat.rds`. To rebuild them, use that module's `run_shared.sh`. |
| OG feature metadata and formal marker tables | Included in `../og_sum_conservation/` for `calicoblast`, `gastrodermis_alga_hosting` and `cnidocyte`. |
| RNA Seurat objects | Download externally and set paths in `../og_sum_conservation/config/species_manifest.tsv`; used for member contributions. |
| Gene–OG mapping and OG annotations | Project-local paths in `config/analysis_config.json`, linking the OG_SUM and gene_annotation modules. |
| OG annotation and TF-member summaries | `inputs/og_annotations.tsv` and `inputs/tf_member_summary.tsv`. |
| TF-member evidence and target/display tables | `results/tf_og_member_evidence.tsv` and `config/`. |

## Running the scripts

Run from this module directory using the supplied OG_SUM objects and externally downloaded RNA objects:

```bash
python3 scripts/run_all.py
```

The runner calls `01_statistics.R` for all 11 species, then executes:

| Stage | Function |
|---|---|
| `01_statistics.R` | Reuse formal OG_SUM markers for the three comparisons above; calculate other native cell-type contrasts and TF expression summaries from each OG_SUM object. |
| `02_select.R` | Select TF80 OGs, count species support and identify conserved associations. |
| `03_plot_data.R` → `04_labels.py` | Prepare overview/per-comparison matrices and annotation labels. |
| `run_members.py` | Run `05_member_contribution.R` for all species, then `06_finalize.R` to combine member support. |
| `07_plot.R` | Draw overview and per-comparison heatmaps. |
| `08_validate_statistics.R` → `09_validate_report.py` | Check statistics, member annotations, plotting data and PDFs. |

For a single species, the statistical entry is:

```bash
Rscript --vanilla scripts/01_statistics.R "$PWD" Adig
```

## Final output

| Location | Contents |
|---|---|
| `results/by_species/<species>/` | Eleven supplied `all_celltypes.OG_SUM.all_tested.tsv.gz` tables and eleven `TF_OG.species_celltype_details.tsv.gz` tables: marker statistics, expression summaries and TF coverage. |
| `results/member_contribution/<species>/` | Saved reconstruction checks (`validation.tsv`); `run_members.py` generates the gene-level and OG-level contribution tables. |
| `results/TF_OG.comparison_conservation.tsv.gz` and `TF_OG.selected_associations.with_member_support.tsv` | Conservation by comparison and selected associations with member evidence. |
| `results/plot_data/` and `results/transposed_plot_data/` | Expression matrices and plot annotations generated by steps 02–04. |
| `figures/` | Overall and per-comparison heatmaps; 28 adopted PDFs are included. |
