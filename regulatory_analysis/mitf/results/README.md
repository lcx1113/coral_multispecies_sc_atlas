# Results: source data for Figures 1 and 2

Outputs of the published run (`p_val_adj < 0.05`, `avg_log2FC > 0.25`, 16 annotated cell
types, JASPAR MA0620.4, TSS −2,000/+500 bp). They are included so that both figures can be
inspected and regenerated without rerunning the scans.

| File | Content | Figure |
|---|---|---|
| `tables/cluster_mitf_enrichment.tsv` | enrichment for all 16 cell types | Figure 1 |
| `tables/motif_robustness.tsv` | enrichment across eleven matrices | Figure 2 |
| `figures/fig1_cluster_enrichment.pdf` | per-cell-type element frequency | Figure 1 |
| `figures/fig2_motif_robustness.pdf` | odds ratios across matrices | Figure 2 |

Rerunning `code/run_all.sh` on the inputs listed in the root README reproduces the two tables
exactly; the figure PDFs differ from these copies only in the PDF creation timestamp. The
large intermediates (`promoters.fa`, `scans/`) are not stored here; they are regenerated by
`code/01_build_promoters.py` and `code/03_run_scans.sh`.

---

## `cluster_mitf_enrichment.tsv` (Figure 1)

One row per cell type.

| Column | Description |
|---|---|
| `cluster` | cell-type label (`focus_node`) |
| `gene_set` | `sig_markers` = `p_val_adj < 0.05` and `avg_log2FC > 0.25` |
| `n_genes` | target genes with a scannable full-length promoter |
| `n_with_hit` | target genes with ≥ 1 predicted element |
| `frac_with_hit` | `n_with_hit / n_genes` |
| `bg_frac_with_hit` | same fraction among the background genes |
| `odds_ratio` | odds ratio from the 2 × 2 table (target vs background × element vs none) |
| `fisher_p` | two-sided Fisher exact test, uncorrected |
| `median_hits_per_kb` | median element density in target genes |
| `bg_median_hits_per_kb` | median element density in background genes |
| `mwu_bestscore_p` | one-sided Mann–Whitney test on each gene's best PWM score, target > background |
| `fisher_q` | Benjamini–Hochberg FDR across the 16 cell types |

For `gastrodermis_alga_hosting`: `n_genes = 413`, `n_with_hit = 150`,
`frac_with_hit = 0.3632`, `bg_frac_with_hit = 0.2647`, `odds_ratio = 1.585`,
`fisher_p = 2.27 × 10⁻⁵`, `fisher_q = 3.63 × 10⁻⁴`.

## `motif_robustness.tsv` (Figure 2)

One row per matrix (all rows use the `prox2kb` window).

| Column | Description |
|---|---|
| `motif` | JASPAR matrix id; `SCD_MA0620.4` is the scrambled control |
| `window` | promoter window (`prox2kb` = TSS −2,000/+500 bp) |
| `gene_set` | `sig_markers` |
| `n_genes` | target genes analysed |
| `frac_with_hit` | fraction of target genes with ≥ 1 element |
| `bg_frac_with_hit` | fraction of background genes with ≥ 1 element |
| `n_bg`, `n_bg_with_hit` | background size and number with ≥ 1 element |
| `odds_ratio` | odds ratio |
| `fisher_p` | two-sided Fisher exact p value |

The eleven matrices are MA0620.4 (human MITF), MA1899.1 (*Ciona* Mitf), MA2257.1
(*Drosophila* Mitf), MA0831.3 (TFE3), MA0692.2 (TFEB), MA0036.3 (GATA2), MA0143.5 (SOX2),
MA0901.3 (HOXB13), MA1870.2 (FoxL2), MA1109.2 (NEUROD1) and SCD_MA0620.4 (scrambled MITF).

## Intermediate files

| File | Description |
|---|---|
| `promoters.bed` | BED6 + window name for every extracted window |
| `promoters.fa` | window sequences in gene orientation; header carries gene, window, coordinates, TSS offset, length and clipped bases |
| `gene_tss.tsv` | gene-level table: representative transcript, TSS, strand, window coordinates, clipping, TSS offset |
| `scans/<matrix>.prox2kb.hits.tsv` | all positions passing `p < 1e-4` (one row per element) |
| `scans/<matrix>.prox2kb.gene.tsv` | one row per gene: hit count, best score, best p/q, best position, promoter length, number of tested positions |

Coordinates in BED-like fields are 0-based, half-open; `tss_relative` positions are 1-based
offsets from the TSS in gene orientation (0 = the TSS base, negative = upstream).
